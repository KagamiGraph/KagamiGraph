# Changelog

All notable changes to KagamiGraph will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.1] - 2026-08-24
### Added
- Initial monorepo scaffolding.
- Docker Compose setup for PostgreSQL and Qdrant vector database.
- Base API gateway initialized in Go (`api/`).
- Base AI Engine initialized in Python with FastAPI (`engine/`).
- Base Studio dashboard initialized with Next.js (`studio/`).
- Added AGPLv3 License.
- Set up initial OSS documentation (README, CONTRIBUTING, CHANGELOG).
